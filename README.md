# Publiczne meteogramy

Repozytorium statycznych plików publikowanych automatycznie przez prywatne `ruby15/meteo-generator`.

Publiczna strona po aktywowaniu GitHub Pages: https://ruby15.github.io/slackness-sandal-outgoing/

**Nie umieszczaj tutaj kodu generatora, prywatnej konfiguracji, tokenów ani sekretów.**

`index.html`, pliki `.png` i `state.json` będą aktualizowane przez GitHub Actions z prywatnego repozytorium.
